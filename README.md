# Zoko — Restaurant Website

A responsive Hebrew (RTL) website for **Zoko**, my smoked-meat restaurant in Tel Aviv. Designed and built from scratch by **Guy Gilboa**.

## Features

- **Full-screen video hero** with mute toggle and a short "atmosphere" reel
- **Menu** with dish cards and the full printed menu
- **Video gallery** — "a bit of our day" in the kitchen and on the smoker
- **Events & happy hour** sections
- **Chat assistant** that answers common questions (hours, location, menu, events) with quick-reply buttons
- **Contact form** connected to an email service (Formspree)
- Mobile navigation, smooth scrolling and a sticky header

## Tech

Plain **HTML5, CSS3 and vanilla JavaScript** — no framework, no build step.

```
zoko_website/
├── index.html
├── css/styles.css
├── js/main.js        # navigation, chat assistant, contact form, video controls
└── assets/           # images and (compressed) videos
```

## Run it

Open `zoko_website/index.html` in a browser, or serve the folder:

```bash
npx serve zoko_website
```
